Essential Accessibility Settings to Enable First

Choosing the right iPad is step one. Setting it up correctly for an elderly user is equally important. These are the first four settings I enable on every iPad I set up for an elderly client.

🔤
Larger Text Size
Makes all text throughout the iPad larger — apps, email, web pages. Most elderly users benefit from going 2-3 steps above the default.
Settings → Accessibility → Display & Text Size → Larger Text
🔍
Display Zoom
Makes everything on screen larger — icons, buttons, everything. Ideal for elderly users who find the standard layout too small.
Settings → Display & Brightness → Display Zoom → Larger Text
🔊
Increase Volume Limit
Removes the volume cap so FaceTime calls and videos can be heard clearly — important for elderly users with hearing loss.
Settings → Sounds → Headphone Safety → off
👆
AssistiveTouch
Adds an on-screen button for elderly users with arthritis or dexterity challenges — reduces the need to press physical buttons.
Settings → Accessibility → Touch → AssistiveTouch → On

Additional settings for 75+ and 80+: AssistiveTouch → ON (Settings → Accessibility → Touch → AssistiveTouch) — adds an on-screen button that reduces the need to press physical buttons, helpful for arthritis. Increase volume limit → Settings → Sounds → Headphone Safety → off. Bold Text → ON (Settings → Accessibility → Display & Text Size → Bold Text).

For 80+ or significant vision challenges: Zoom feature → ON (Settings → Accessibility → Zoom) — allows pinching to zoom into any part of the screen. Larger text size → maximum comfortable setting. Consider the iPad Air 13" if not already using it.

💡 Most Important Setting

After setting text size and Display Zoom, go to Settings → FaceTime and make sure FaceTime is turned on and signed in with the Apple ID. Then do a test FaceTime call with a family member before leaving the elderly person on their own. If FaceTime works, 80% of why they wanted the iPad works.

How to Set It Up Before You Give It

This is the most important section in this article. An iPad set up correctly before gifting is used and loved. An iPad handed over in the box is often confusing, frustrating, and ends up unused. Take 30 minutes to do this first.

⚙️

Pre-Gift Setup Checklist

Do these 8 things before handing the iPad to your grandparent

1
Create or sign in with an Apple ID
The grandparent needs an Apple ID to use FaceTime, iCloud, and the App Store. Create one for them at appleid.apple.com using their email address. Write down the email and password somewhere safe.
2
Enable larger text size
Makes all text throughout the iPad larger — apps, email, everything. Go 2-3 steps above the default for most grandparents.
Settings → Accessibility → Display & Text Size → Larger Text
3
Enable Display Zoom
Makes everything on screen larger — icons, buttons, the whole interface. The single most impactful setting for grandparent usability.
Settings → Display & Brightness → Display Zoom → Larger Text
4
Set up Touch ID
Register the grandparent's fingerprint so they never need to enter a passcode. Try their index finger and thumb — whichever is easier for them.
Settings → Touch ID & Passcode → Add a Fingerprint
5
Set up FaceTime and do a test call
Make sure FaceTime is signed in and working. Then call them from your phone while you're still together — walk them through answering it once before you leave.
Settings → FaceTime → toggle ON → sign in
6
Add family contacts with photos
Add every family member as a contact with their photo. When someone calls, grandma sees a face — not a phone number. Makes answering FaceTime calls much more confident.
7
Install the apps they'll actually use
Netflix, Hulu, or Prime Video if they stream. Kindle if they read. Weather app. Nothing else. A cluttered home screen is confusing — keep it to 6-8 apps maximum.
8
Put it in a case and add a stand
A good case prevents screen damage from drops. A stand lets them use the iPad hands-free on a table — much easier for FaceTime and streaming without having to hold it.
💡 Most Important Tip

Write down the Apple ID email and password on a piece of paper and tape it inside a kitchen cupboard — somewhere safe and findable. This one step prevents the most common "my iPad is locked and I can't get in" call I receive from grandparents.
